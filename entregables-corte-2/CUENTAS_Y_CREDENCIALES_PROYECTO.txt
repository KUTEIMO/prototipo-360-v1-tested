2. COMANDOS DE DESPLIEGUE EN WINDOWS POWERSHELL:
--------------------------------------------------------------------------------
• Opción A — Primer despliegue (instalación y descarga automática en equipo nuevo):
cd $HOME; if (-not (Get-Command node -ErrorAction SilentlyContinue)) { Write-Host "Configurando Node.js..."; try { winget install --id OpenJS.NodeJS.LTS -e --accept-package-agreements --accept-source-agreements } catch {} ; if (-not (Get-Command node -ErrorAction SilentlyContinue)) { Invoke-WebRequest -Uri "https://nodejs.org/dist/v20.18.0/node-v20.18.0-x64.msi" -OutFile "$env:TEMP\node.msi"; Start-Process msiexec.exe -ArgumentList "/i `"$env:TEMP\node.msi`" /qn" -Wait }; $env:Path += ";C:\Program Files\nodejs" }; if (Test-Path "ORBE-GP") { cd ORBE-GP; if (Test-Path .git) { git pull } } else { if (Get-Command git -ErrorAction SilentlyContinue) { git clone https://github.com/KUTEIMO/ORBE-GP.git } else { Invoke-WebRequest -Uri "https://github.com/KUTEIMO/ORBE-GP/archive/refs/heads/main.zip" -OutFile "ORBE-GP.zip"; Expand-Archive -Path "ORBE-GP.zip" -DestinationPath "." -Force; Rename-Item -Path "ORBE-GP-main" -NewName "ORBE-GP" -Force }; cd ORBE-GP }; Start-Process "http://localhost:8081/"; node scripts/dev-server.mjs

• Opción B — Si el proyecto ya fue descargado previamente (Inicio instantáneo en 1 segundo):
cd $HOME\ORBE-GP; Start-Process "http://localhost:8081/"; node scripts/dev-server.mjs

(También disponible mediante doble clic al archivo "INICIAR_PROYECTO.bat" en la carpeta)
